## Estructura de cada rediseño

```
/claude
  index.html        ← demo en un solo archivo (HTML/CSS/JS vanilla)
  /assets           ← assets reales exportados desde Figma
  /pantallas        ← referencias de los frames originales de Figma
```

---

## Stack y herramientas

- **Diseño:** Figma — extracción pixel-perfect con assets reales exportados
- **Código:** HTML + CSS + JS vanilla, sin dependencias
- **Técnicas:** Glassmorphism, escalado responsivo con `transform: scale()`, custom properties CSS, navegación con touch / teclado / swipe
